# 02 – Ubuntu Server Installation

## Objective
To install and configure Ubuntu Server 24.04.1 LTS inside the virtual machine.

## Operating System
Ubuntu Server 24.04.1 LTS

## Installation Procedure

1. Started the `Linux-Server` virtual machine in VirtualBox.
2. Attached and booted from the Ubuntu Server ISO image.
3. Selected English as the installation language.
4. Proceeded through the Ubuntu Server installation process.
5. Configured the network interface using the available default settings.
6. Reviewed the Ubuntu archive mirror configuration and retained the default mirror.
7. Completed the system installation.
8. Restarted the virtual machine.
9. Logged into Ubuntu Server using the created username and password.

## Verification

After installation, the Ubuntu login prompt was displayed successfully.

The server provided access to the Linux command-line interface.

## Result

Ubuntu Server 24.04.1 LTS was successfully installed and the user was able to log in to the system.
