# 01 – Virtual Machine Setup

## Objective
To create a virtual machine using Oracle VirtualBox that will host the Ubuntu Server operating system.

## Software Used
- Oracle VirtualBox
- Ubuntu Server 24.04.1 LTS ISO

## Virtual Machine Configuration

| Component | Configuration |
|---|---|
| VM Name | Linux-Server |
| Operating System | Ubuntu Linux (64-bit) |
| RAM | 2 GB |
| Virtual Disk | 25 GB |
| Network Adapter | NAT |

## Procedure

1. Installed and opened Oracle VirtualBox.
2. Downloaded the Ubuntu Server 24.04.1 LTS ISO image.
3. Created a new virtual machine named `Linux-Server`.
4. Selected Ubuntu Linux (64-bit) as the operating system.
5. Allocated 2 GB of RAM.
6. Created a virtual hard disk with 25 GB of storage.
7. Configured the network adapter to use NAT.
8. Attached the Ubuntu Server ISO image to the virtual machine.

## Result

The virtual machine was successfully created and configured, providing an environment for installing and running Ubuntu Server.
